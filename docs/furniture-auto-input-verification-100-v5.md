## 変更内容

サイズ欄全体の拡大では、オルトの撮影機材の5×5が3×5に、ヴィルの撮影機材の5×5が5だけになる前処理があり、採用条件を満たさなかった。既存処理が保留の場合だけ、次の補助処理を使う。

1. 3つの文字領域を確認し、端で切れた文字や左右の数字の高さの不整合を除外する。
2. 中央の記号に「×」の4方向の斜線があることを確認する。
3. 明るさ閾値150・170で文字を抽出し、余白を除いて高さ32ピクセルに正規化する。
4. 両方のOCRが「1桁×1桁」の形式・信頼度55以上を満たして一致した場合だけ、積をマス数に採用する。

家具名による分岐、25マスの固定値、撮影機材の専用認識テンプレートは追加していない。既存のテンプレート59個は変更していない。
