## 評価条件

- 投稿を新しい順に確認し、既存200家具と名前の正規化後および画像IDが重複しない100投稿を選んだ。追加分は2024-11-11〜2025-04-16（日本時間）、画像2枚以上の個別家具投稿。認識結果による選別はしていない。無作為抽出ではなく、同じ投稿者・端末・シリーズに偏る。
- 100家具を目視確認して正解値を固定した後に認識を実行。所持上限は「所持 x / 上限」の分母。シリーズボーナスはオンボロ風の基準14を除いた加算値。寮ポイントは画面上の対象寮の値。
- いごこち度・シリーズボーナス・寮ポイント・レアリティ・マス数・テーマ2種・寮・所持上限・製作マドル・一般素材9種を評価。画像にない値や「－」のマス数は正解分母に入れない。塗料・結晶・イベント専用素材は対象外。ホリデーイルミネーション等の黄色い限定マーク付き素材を通常素材として採用した場合は、対象外素材の誤採用として数える。
- 家具名は投稿を使用し、テーマグラフの読み取りは行わない。これは画像認識の評価であり、計算式を含むシート全列の完成率や本番自動入力成功率ではない。
- 追加366画像はDiscordの元添付を取得したもの。取得後の拡大縮小やJPEG再エンコードはしていない。拡張子は .png に統一されているが、PNG/JPEGは実データをデコードして検証。原画像のバイト列・寸法・SHA-256を記録した。以前のブラウザ取得画像が含まれる既存698画像は変更していない。
- 画像はGit管理外の `.local/samples/` に保存。認識コード等84ファイル、正解ラベル、分類情報、全画像のハッシュを確認した。新規素材からのテンプレート追加は行っていない。

## 保留・誤採用の詳細

| 原因 | 家具数 | 保留 | 誤採用 | 確認内容 |

| イベント専用素材と通常素材の混同 | 10 | 0 | 27 | ホリデーイルミネーション等。限定マークが付いた素材を一般素材の絵柄と一致させ、通常素材の列へ数量を出力した。数値自体の読み違いではなく、素材の種類の取り違え。 |

## 再現・保存先

25家具ずつ12バッチ、最大4プロセスで実行。中断前に完了した4バッチ（100家具）を再利用し、残り8バッチ（200家具）を再実行した。再開後の経過時間は561.8秒で、全300家具を一度に処理した所要時間ではない。中断前の未完了バッチではローカルTesseractの起動エラー（終了コード3221225794）が発生していた。自動テスト77件が成功。Northflank上の性能やBot全体の処理時間を測定したものではない。

```powershell
.venv/Scripts/python.exe scripts/verify_furniture_samples.py .local/samples --labels tests/fixtures/furniture_samples_300.json --context tests/fixtures/furniture_samples_300_context.json --output .local/verification-300-v6.json
.venv/Scripts/python.exe -m unittest discover -s tests -q
```

正解ラベルは `tests/fixtures/furniture_samples_300.json`、分類の出所は `tests/fixtures/furniture_samples_300_context.json`。全300家具の採用値・エラー・ハッシュ・追加分の投稿監査は [JSON](furniture-auto-input-verification-300-v6.json)、全認識根拠は `.local/verification-300-v6.json` に保存。Discordへの投稿、本番シート書込み、push、Northflankデプロイは実施していない。
