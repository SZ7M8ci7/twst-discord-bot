## 変更した認識処理

- いごこち度の白い数字を2つの明るさ閾値で抽出し、高さ48ピクセルに揃えてOCRを照合。文字の周囲を含めて一律に大きく拡大する方法を置き換えた。空白・画像端で切れた数字・両処理の不一致は採用しない。
- ベーシックの専用テンプレートを追加。切出し元は従来の調整用家具「グレート・ルック（ジャミル）」の測定画面にあるテーマラベルのアイコン。グラフの頂点や数値を読む処理は追加していない。
- 投稿分類が床・壁紙の場合、測定時のNRC基準ポイントを27、それ以外を36として検証。分類はBotとオフラインCLIの両方から認識処理へ渡す。
- 寮なし表示の薄いラベルを通常・平滑化照合で確認し、従来の横棒形状チェックも残した。
- 寮ポイント0は、通常照合に加えて紋章部分を除いた数字全体の通常・平滑化照合でも確認。5・36・空白を0にしない回帰テストを追加した。
- 位置がずれたマス数欄は既存のラベル確認を残し、通常・平滑化の条件を組み合わせて補助する。
